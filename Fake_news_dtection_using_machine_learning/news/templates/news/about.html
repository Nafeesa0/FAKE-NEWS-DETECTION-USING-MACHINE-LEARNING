Project Overview

What Is InfoTrust?

InfoTrust is an advanced web-based platform that combats the global misinformation crisis using state-of-the-art deep learning technology. At its core is a Bidirectional LSTM neural network — trained on nearly 45,000 articles — that analyses linguistic patterns, narrative structure, and contextual signals to distinguish real news from fabricated content.

In today's digital landscape, misinformation spreads faster than fact. InfoTrust provides instant, AI-backed verification so that individuals, researchers, and educators can make informed decisions before sharing content. Every article verified through our platform contributes to a growing record that helps track misinformation trends over time.

Neural Network Architecture

Bidirectional LSTM
Deep Neural Network

Unlike standard RNNs, the BiLSTM processes text sequences in both forward and backward directions simultaneously — capturing context that appears later in the article and using it to better understand earlier passages.

Two stacked BiLSTM layers (128 then 64 units) extract increasingly abstract features, while dropout layers prevent overfitting. The sigmoid output maps to a probability score between 0 (real) and 1 (fake).

Verification Pipeline

How Verification Works

Every article submitted to InfoTrust passes through a six-stage pipeline from raw text to AI verdict. Each stage is designed to maximise accuracy and minimise noise.

1
News Collection

Articles are scraped from trusted sources — BBC, Reuters, CNN — by our automated Celery Beat scheduler that runs every hour without manual intervention.

2
Text Preprocessing

Raw text is cleaned using NLTK: HTML stripping, lowercasing, special character removal, URL elimination, and whitespace normalisation.

3
Tokenization & Lemmatization

Text is split into tokens. Stopwords are removed. WordNet lemmatization reduces words to their root form (e.g. "running" → "run") for vocabulary normalisation.

4
Sequence Padding

The trained Keras Tokenizer maps each word to an integer ID. Sequences are padded or truncated to a fixed length of 500 tokens for uniform model input.

5
BiLSTM Inference

The 7-layer Bidirectional LSTM model processes the padded sequence and outputs a probability between 0 and 1. Values above 0.5 are classified as fake.

6
Result Display

The verdict, confidence score (%), and probability breakdown (fake vs real) are displayed instantly. Results are stored in the database for analytics.

Real-Time Scraping Infrastructure

Automated Hourly
News Collection

InfoTrust uses Celery — a distributed task queue — backed by Redis as the message broker to run fully automated scraping jobs every hour, completely without manual intervention.

The Celery Beat scheduler dispatches the auto_scrape_news task at the top of every hour. The worker picks it up, scrapes all configured sources, verifies each article with the AI model, deduplicates, and logs the run — all in the background while the web server continues handling requests normally.

# Start Redis (Docker)
docker run -p 6379:6379 redis

# Start Celery worker
celery -A fake_news_detector worker --loglevel=info

# Start Beat scheduler
celery -A fake_news_detector beat --loglevel=info

Duplicate Detection
Articles already in the database (matched by title) are automatically skipped to avoid redundant AI inference.
Auto-Retry on Failure
If the task fails (e.g. network error), Celery automatically retries up to 3 times with a 5-minute cooldown between attempts.
ScrapingLog Audit Trail
Every run (scheduled or manual) writes a log entry with status, articles saved/skipped/errored, and duration — visible on the Statistics page.
Manual Trigger Available
The Scrape News page also lets you dispatch the task on-demand via a single button click, without waiting for the scheduled run.
